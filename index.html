Как будет проходить покупка

Пока сайт работает как первая версия. Аккаунтов не будет: покупка привязывается к ключу, а не к профилю пользователя.

Оформление без регистрации

Клиент выбирает тариф, оплачивает доступ и получает ключ для приложения. Позже здесь можно добавить форму заявки или кнопку оплаты.

1. Выбрать тариф: Личный / Личный+ / Семейный
2. Получить ключ после подтверждения
3. Ввести ключ в приложении Skryon

Правила и прозрачность

Политика конфиденциальности

Сайт не использует аккаунты. Для выдачи доступа может храниться только информация, необходимая для ключа: тариф, срок действия и статус доступа.

Условия использования

Ключ предназначен для выбранного количества устройств. Передача ключа третьим лицам может привести к замене или отключению доступа.
